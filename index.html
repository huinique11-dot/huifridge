🥬 우리집 냉장고

📷 영수증으로 담기 — 사진 찍거나 앨범에서 고르면 식품 품목만 자동으로 인식해요. 인식 결과에서 이름을 고치고 필요없는 줄은 지운 뒤 "냉장고에 담기"를 눌러요.

✍️ 직접 추가하기 — 이름을 입력하면 카테고리가 자동으로 추측돼요(수정 가능). 직접 만든 반찬은 소비기한 대신 "만든 날짜"를 넣으면 "N일째"로 표시돼요.

⚙ 보관장소 관리 — 냉장실/냉동실/실온 외에 김치냉장고처럼 우리집만의 보관장소를 자유롭게 추가·삭제할 수 있어요.

정렬·보기 방식 — 목록 위 버튼으로 기한순/가나다순 정렬을 바꾸고, "간단히"를 누르면 카테고리·보관장소·날짜 없이 이름과 기한만 한 줄로 보여서 스크롤이 짧아져요. "간단히" 모드에서도 기한 뱃지를 탭하면 그 재료만 카테고리·보관장소·기한을 바로 수정할 수 있어요.

🏷️ 카테고리 필터 — 보관장소 탭 아래에 카테고리 칩이 떠요. 채소·고기처럼 카테고리를 눌러 그 종류만 골라볼 수 있어요.

뱃지 색깔 — 🔴 만료·오늘까지 🟠 3일 이내 🟡 7일 이내 🟢 여유 있음 ⚪ 기한 미설정

📋 레시피 찾기 — 재료 체크박스를 선택하고 "레시피 검색하기"를 누르면 재료가 복사되면서 네이버 검색이 바로 열려요.

🔀 여러 개 한번에 옮기기 — 재료 체크박스를 여러 개 선택하면 "카테고리 일괄변경"·"보관장소 일괄변경" 드롭다운이 나와요. 골라놓은 재료들을 한 번에 다른 카테고리나 보관장소로 옮길 수 있어요.

📷 영수증으로 한번에 담기

영수증 사진을 찍거나 앨범에서 선택하면 식품 품목만 자동으로 인식해드려요.

인식 준비 중...

자동으로 품목을 찾지 못했어요. 아래 인식된 원본 글자를 보고 "✍️ 직접 추가하기"로 넣어주세요.

🔍 인식된 품목 확인

이름을 수정하고, 필요없는 항목은 지운 뒤 소비기한을 입력해주세요.

✍️ 직접 추가하기

🧾 보관 중인 재료 (0)

냉장실, 냉동실, 김치냉장고, 실온 등 우리집에 맞게 보관장소를 자유롭게 추가·수정·삭제하세요.

냉장고 재고와는 별도로, "이번에 사야 할 것" 목록이에요.

🏬 진열대에서 골라 담기 — 펼치면 마트처럼 카테고리별 매대가 나와요. 카테고리를 고르고 품목을 탭하면 바로 목록에 담겨요.

1. 진열대에 없는 품목은 이름을 직접 입력하고 "추가"를 눌러요. 카테고리는 자동으로 분류돼요.

2. 실제로 사면 체크박스를 눌러 구매완료로 표시해요. "전체선택"을 누르면 담긴 품목을 한 번에 다 체크할 수 있어요.

3. 상단 "🧊 냉장고로 담기"를 누르면 체크한 항목만 바로 냉장고에 담겨요. 소비기한·보관장소는 냉장고 탭에서 나중에 정해주면 돼요.

📝 계획 추가 — 아직 안 만든 요리를 미리 적어둬요. 날짜를 직접 골라서 이번 주, 다음 달 식단도 미리 계획할 수 있어요. "냉장고에서 재료 고르기"를 펼쳐서 탭하거나 직접 입력해요.

🍳 요리 완료로 기록하기 — 계획 카드에서 누르면 별점을 매기고, 사진도 추가할 수 있고, 실제 쓴 재료를 체크해서 냉장고 재고에서 뺄 수 있어요. 저장하면 계획 → 완료 기록으로 바뀌어요.

+ 기록 추가 — 계획 없이 이미 만든 요리를 바로 기록할 때 써요. 📷 사진도 선택해서 넣을 수 있어요(화질 낮게 자동 저장돼서 용량 걱정 안 하셔도 돼요) — 메뉴판에도 같이 보여요.

고치기·지우기 — 제목을 탭하면 바로 수정돼요(별도 버튼 없음). 삭제는 ✕ 한 번으로 바로 지워져요.
